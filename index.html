Reliability quick notes

  • Battery: Ask for powercfg /batteryreport or test unplugged 30+ minutes. 80%+ capacity is good; 50–70% = mostly desk use.
  • SSD: Prefer 256 GB NVMe; 128 GB only if very cheap or easy to upgrade.
  • Pay: Cash or PayID on pickup after testing. Prefer eBay for buyer protection when posting.
Pre-purchase checklist

Tap each row to tick. Progress is saved in this browser (local storage).

  • Cold boot to desktop — no BSOD
  • Charger included, genuine, charges (LED on)
  • 8 GB+ RAM confirmed (Settings / BIOS)
  • SSD not HDD; capacity matches ad (~256 GB)
  • Battery: report or 2+ hours at medium brightness
  • All keyboard keys, trackpad, USB ports
  • Display: no cracks; check bright spots on white page
  • Wi‑Fi, webcam, speakers
  • No BIOS password; no theft / activation locks
  • Receipt or message trail if warranty claimed
  • If ad claims touch / fingerprint — verify in OS settings
